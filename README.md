# The Elder Care Command Binder: sales site

Static site, no build step.

1. Open `index.html` and find the `STORE` block near the bottom.
2. Paste your Creem checkout links into `url` for each edition.
3. Optionally add prices (for example `"$19"`). Leave `price` empty to hide it.
4. Push to GitHub, then Settings > Pages > deploy from the `main` branch, root folder.
